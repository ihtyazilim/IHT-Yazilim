# AppGather & IHT Windows

**AppGather**, Windows sisteminizi tek noktadan yönetmenizi sağlayan hepsi bir arada (all-in-one) masaüstü uygulamasıdır. **IHT Windows** projesi ile tam entegre çalışacak şekilde tasarlanmıştır.

---

## 🚀 Öne Çıkan Özellikler

### 🛠️ AppGather Sistem Yöneticisi
* **Toplu Yazılım Kurulumu (Ninite Mantığı):** İhtiyacınız olan programları tek tıkla, arayüzlerle uğraşmadan arka planda sessizce kurun.
* **Gelişmiş İnce Ayarlar (WinUtil Mantığı):** Gereksiz Windows hizmetlerini devre dışı bırakın, gizlilik ve performans ayarlarını yapılandırın.
* **Canlı Kaynak İzleme (Görev Yöneticisi Mantığı):** CPU, RAM, Disk ve ağ kullanımını anlık grafiklerle izleyin, süreçleri yönetin.
* **Derinlemesine Donanım Analizi (HWInfo64 Mantığı):** İşlemci, ekran kartı, bellek ve anakart donanım verilerini detaylarıyla görüntüleyin.

### 💿 IHT Windows Özellikleri
* **Bloatware-Free:** Sistemdeki tüm gereksiz Microsoft uygulamaları ve şişkinlikler temizlenmiştir.
* **Telemetri Kapalı:** Veri toplama servisleri ve arka plan ajanları tamamen iptal edilerek maksimum gizlilik sağlanmıştır.
* **Yüksek Stabilite & Performans:** Arka plan yükleri hafifletilmiş, düşük gecikme ve yüksek FPS/hız odaklı optimize edilmiştir.
